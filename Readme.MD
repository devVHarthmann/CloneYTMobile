# YTclone
 
Projeto feito no Android Studio como cópia visual do aplicativo do YouTube para Android. O objetivo é reproduzir a interface (tela inicial, barra de categorias, lista de vídeos e barra de navegação), sem nenhuma funcionalidade real.
 
## O que tem
 
- Tela inicial com barra superior (logo, busca, notificações)
- Lista de categorias em chips
- Feed de vídeos com miniatura, título, canal e duração
- Barra de navegação inferior
## O que não tem
 
- Reprodução de vídeo
- Busca funcional
- Login ou conta de usuário
- Conexão com internet ou dados reais
Todos os vídeos, canais e visualizações são fictícios, usados apenas para preencher a tela.
 
## Tecnologias
 
- Kotlin
- Jetpack Compose
- Material 3
## Como rodar
 
1. Abrir o projeto no Android Studio
2. Esperar o Gradle sincronizar
3. Rodar em um emulador ou celular com o botão Run
